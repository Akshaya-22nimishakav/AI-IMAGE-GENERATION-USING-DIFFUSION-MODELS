# AI Image Generation using Diffusion Models

## 📌 Project Overview

This project demonstrates AI-based image generation using diffusion models. It uses deep learning techniques to generate high-quality images from noise.
The system takes a **textual prompt from the user** and generates a corresponding **AI-based image based on the given description**.

## 🚀 Features

* Image generation using diffusion models
* Converts user **text prompts into images**
* Generates high-quality AI-based visuals
* Implemented in Google Colab
* Uses deep learning frameworks

## 🛠️ Technologies Used

* Python
* PyTorch / TensorFlow
* Diffusion Models
* Google Colab

## ▶️ How to Run

1. Open the notebook in Google Colab
2. Install required libraries
3. Provide a **text prompt as input**
4. Run all cells to generate the image
